# Marka varlıkları

Üç logo konsepti (A Zirve, B Göl, C Monogram). Önizleme: `preview.png`. Yeniden üretmek için: `cd brand && node build.js`
(PNG'ler `web/node_modules` içindeki Playwright/Chromium ile çizilir).

**Renkler:** lacivert `#1B3A6B` · derin lacivert `#10264A` · mavi `#2B5CA6` · kırmızı `#D53E35`.

| Klasör | İçerik |
|---|---|
| `svg/` | `*-icon.svg` (yuvarlak köşeli), `*-icon-store.svg` (tam kare), `*-lockup-light/dark.svg` (yatay logo), `*-favicon.svg` |
| `png/` | İkon 48/192/512/1024 ve yatay logo PNG'leri |
| `app-icons/` | Play Store 512, App Store 1024 (tam kare), Android uyarlanabilir ikon ön/arka katmanı (432) |

Not: yatay logolardaki yazı sistem fontlarına (Segoe UI/Helvetica/Arial) dayanır; basılı/son kullanım için PNG'yi veya
tasarımcıda yazıyı eğriye çevirilmiş sürümü kullanın.
