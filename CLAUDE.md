## 1. Proje özeti ve mimari

Bingöl Üniversitesi öğrenci/personel uygulaması: haber-duyuru-etkinlik ve yemek listesi, üyelik (yalnız `bingol.edu.tr`), profil, bildirimler, mesajlaşma, topluluklar, etkinlikler (QR + elle yoklama), favoriler/arama, destek, sözleşmeler, yönetim paneli.

- `backend/` — Spring Boot 4.1.x, Java 17, Maven; PostgreSQL 16 (Flyway), Redis, WebSocket/STOMP, JJWT, jsoup, Firebase Admin (isteğe bağlı), Lombok
- `web/` — React + TypeScript (Vite): herkese açık tanıtım sitesi + `/admin` yönetim paneli (bkz. `web/README.md`)
- `mobile/` — Flutter (iOS/Android), paket `bu_kampus`: kayıt/giriş/doğrulama/şifre sıfırlama + Ana Sayfa, Keşfet, Sohbet (kişi/kulüp/etkinlik, gerçek zamanlı), Kulüpler, Etkinlikler (QR), Yemek, Bildirimler, Arama, Destek, Profil, Ayarlar; açık/koyu tema. Mimari ve derleme: [docs/MOBILE_UI.md](docs/MOBILE_UI.md); tasarım şablonları `mobile/design/*.dc.html`. iOS Windows'tan `xcross` ile derlenir (Türkçe karakterli yolda ASCII junction `C:\bu_mobile`, `PUB_CACHE=C:\pubcache`, Flutter `C:\src\flutter`); mağaza yayını macOS CI'dadır (`.github/workflows/ios-release.yml`, `codemagic.yaml`, `scripts/ios/*`; dosya düzeyi kontrol `python -I -X utf8 scripts/ios/check-ios-static.py`)
- `docker-compose.yml` — postgres, redis, backend (ve varsa web)

Katman kuralı: **Controller → Service → Repository**. Controller yalnızca HTTP eşlemesi + rate limit yapar; entity'ler API'ye doğrudan dönmez, `dto/` (veya modül içi) record'larına çevrilir.

### SPI'lar (modüller arası gevşek bağ)
- `ReportTargetHandler` (moderation): raporlanabilir içerik türleri (USER, MESSAGE, POST, COMMUNITY, EVENT) kendi handler bean'ini yazar.
- `SearchProvider` (search): genel aramaya katılan türler.
- `DataExporter` (export): kullanıcının kendi verisini dışa aktaran bölümler.
- `NotificationService` (notification): `send`, `sendLocalized`, `broadcast(Localized)`, `sendBulk` — diğer modüller bildirimi yalnızca buradan gönderir.

### Redis'in rolü
Doğrulama kodu (`vc:*`), refresh token (`rt:*`, yalnız SHA-256 hash), rate limit (`rl:*`), askıya alınan kullanıcı işareti (`suspended:<id>`), presence (`presence:*`, `lastseen:*`), mesajlaşma pub/sub kanalı, bekleyen kayıt (`reg:<email>`, 1 sa), kod kilidi (`vc:lock:<email>`), oturum iptali (`rtu:<uid>` refresh kümesi, `pwchg:<uid>` şifre/oturum değişim anı), `schedlock:<ad>` görev kilidi. Redis yoksa auth/mesajlaşma çalışmaz; haber/menü okuma uçları Redis'e bağımlı değildir (sunucu okuma önbelleği `cache:<ad>:<sürüm>:<anahtar>` + JVM içi L1; Redis yoksa yalnız L1/DB'ye düşer).

### "Bakımda" mekanizması
Kaynak site değişir/ulaşılmazsa senkronizasyon exception fırlatmaz; `StatusService.markMaintenance` çağrılır, eski veri sunulur. `GET /api/status` → `{NEWS:{maintenance,…}, MENU:{…}}`. Ek olarak yönetici ayarı `maintenance_mode` uygulama genelinde bakım bandı gösterir (`GET /api/app/info`).

## 2. Çalıştırma, derleme, test

**Önemli:** Bu makinede yalnızca **Java 8** var; backend Java 17 ister → derleme/test **Docker'daki Maven 17 konteynerinde** yapılır. Flutter `C:\src\flutter` altında (mobil derleme/test ASCII `C:\bu_mobile` yolundan). Node 24/npm 11 yerelde var (web için).

```bash
# backend/ içinde (Git Bash)
MSYS_NO_PATHCONV=1 docker run --rm -v "$(pwd -W):/app" -w /app maven:3-eclipse-temurin-17 mvn -B test

# tüm yığın
cp .env.example .env        # DB_PASSWORD, JWT_SECRET, ADMIN_PASSWORD zorunlu
docker compose up -d --build
curl localhost:8080/actuator/health
```

- Şema **yalnızca Flyway** ile yönetilir (`ddl-auto=validate`). Testler H2 + `spring.flyway.enabled=false` + `create-drop` kullanır (`src/test/resources/application.properties`; main'deki dosyanın **yerine geçer**, gerekli anahtarlara orada varsayılan verin).
- PostgreSQL'e özel native sorgular H2'de çalışmaz: bunlar **duman betikleriyle** doğrulanır.
- **Duman betikleri** (`scripts/smoke*.sh`, çalışan compose yığınına karşı, ASCII, tekrar çalıştırılabilir; hepsi `docker compose logs backend` ile doğrulama kodunu okur → `MAIL_ENABLED=false`, `ADMIN_EMAILS=$ADMIN_EMAIL`, `ADMIN_PASSWORD`, `LEGAL_ENFORCE_REACCEPT=false`). **Tek komut:** `BASE=http://localhost:8080 ADMIN_PASSWORD=... ./scripts/smoke-all.sh` — tüm `smoke*.sh` betiklerini sırayla koşar, her biri arasında Redis `flushall` yapar, özet tablo (ok/fail/çıkış/süre) basar; herhangi biri başarısızsa çıkış kodu 1 (`ONLY="smoke-poll smoke-search"`, `SKIP="..."`, `LOG_DIR=...`, `FLUSH_CMD=...` ile daraltılır; çıkış kodu 2 = ATLANDI, hata sayılmaz). Betikler: `smoke.sh` (çekirdek), `smoke-support.sh` (destek/sözleşme/i18n/kampanya), `smoke-search.sh` (kullanıcı/kulüp/etkinlik arama her zaman; haber/favori adımları haber yoksa ATLA), `smoke-messaging.sh`, `smoke-chat-groups.sh`, `smoke-chat-receipts-video.sh`, `smoke-communities-events.sh` (`SKIP_REMINDER=1` ~3 dk'lık hatırlatma adımını atlar), `smoke-events-featured.sh`, `smoke-club-lifecycle.sh`, `smoke-academic.sh`, `smoke-crash-reports.sh`, `smoke-poll.sh`, `smoke-posts.sh`, `smoke-post-social.sh`, `smoke-profanity.sh`, `smoke-push-outbox.sh`, `smoke-block-shadow.sh`, `smoke-contacts-match.sh`, `smoke-single-session.sh`, `smoke-student-number.sh`, `smoke-access-ban.sh`, `smoke-admin.sh`, `smoke-admin-{bulk,chat,communities,events,mailops,moderation,pushops,retention,support,users,verify}.sh`; ayrıca `SLOW=1 node scripts/ws-test.js`.
