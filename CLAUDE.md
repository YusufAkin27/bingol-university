## 1. Proje özeti ve mimari

Bingöl Üniversitesi öğrenci/personel uygulaması: haber-duyuru-etkinlik ve yemek listesi, üyelik (her geçerli e-posta + e-posta kodu), profil, bildirimler, mesajlaşma, topluluklar, etkinlikler (QR + elle yoklama), favoriler/arama, destek, sözleşmeler, yönetim paneli.

- `backend/` — Spring Boot 4.1.x, Java 17, Maven; PostgreSQL 16 (Flyway), Redis, WebSocket/STOMP, JJWT, jsoup, Firebase Admin (isteğe bağlı), Lombok
- `web/` — React + TypeScript (Vite): herkese açık tanıtım sitesi + `/admin` yönetim paneli (bkz. `web/README.md`)
- `mobile/` — Flutter (iOS/Android), paket `bu_kampus`: kayıt/giriş/doğrulama/şifre sıfırlama + Ana Sayfa, Keşfet, Sohbet (kişi/kulüp/etkinlik, gerçek zamanlı), Kulüpler, Etkinlikler (QR), Yemek, Bildirimler, Arama, Destek, Profil, Ayarlar; açık/koyu tema. Mimari ve derleme: [docs/MOBILE_UI.md](docs/MOBILE_UI.md); tasarım şablonları `mobile/design/*.dc.html`. iOS Windows'tan `xcross` ile derlenir (Türkçe karakterli yolda ASCII junction `C:\bu_mobile`, `PUB_CACHE=C:\pubcache`, Flutter `C:\src\flutter`); mağaza yayını macOS CI'dadır (`.github/workflows/ios-release.yml`, `codemagic.yaml`, `scripts/ios/*`; dosya düzeyi kontrol `python -I -X utf8 scripts/ios/check-ios-static.py`)
- `docker-compose.yml` — postgres, redis, backend (ve varsa web)

### SPI'lar (modüller arası gevşek bağ)
- `ReportTargetHandler` (moderation): raporlanabilir içerik türleri (USER, MESSAGE, POST, COMMUNITY, EVENT) kendi handler bean'ini yazar.
- `SearchProvider` (search): genel aramaya katılan türler.
- `DataExporter` (export): kullanıcının kendi verisini dışa aktaran bölümler.
- `NotificationService` (notification): `send`, `sendLocalized`, `broadcast(Localized)`, `sendBulk` — diğer modüller bildirimi yalnızca buradan gönderir.

### Redis'in rolü
Doğrulama kodu (`vc:*`), refresh token (`rt:*`, yalnız SHA-256 hash), rate limit (`rl:*`), askıya alınan kullanıcı işareti (`suspended:<id>`, bilinçli olarak TTL'siz; Redis `volatile-lru` onu atmaz), presence (`presence:*`, `lastseen:*`), mesajlaşma pub/sub kanalı, bekleyen kayıt (`reg:<email>`, 72 sa: `app.auth.pending-registration-ttl`; anahtar uzayı `regidx`/`regidxexp` ZSET dizininden listelenir, SCAN yok, yazım `regtmp:` + RENAME ile atomik), kod kilidi (`vc:lock:<email>`), oturum iptali (`rtu:<uid>` refresh kümesi, `pwchg:<uid>` şifre/oturum değişim anı), `schedlock:<ad>` görev kilidi. Redis yoksa auth/mesajlaşma çalışmaz; haber/menü okuma uçları Redis'e bağımlı değildir (sunucu okuma önbelleği `cache:<ad>:<sürüm>:<anahtar>` + JVM içi L1; Redis yoksa yalnız L1/DB'ye düşer).
