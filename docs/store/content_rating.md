# Play Console: içerik derecelendirme anketi (IARC) cevapları

Kategori: **Sosyal / İletişim (kullanıcıların etkileşime girdiği uygulama)** (anketin ilk adımında "Social, communication"/"Utility/Other" benzeri seçeneklerden sosyal ağ/mesajlaşma olanı seçin; oyun değil). E-posta adresi: geliştirici iletişim adresi.

Cevaplar uygulamanın gerçek davranışına göredir; Console'daki soru ifadeleri değişebilir, anlamca eşleştirin. **Anket henüz Console'da doldurulmadı** (hesap gerekir). Sonuç beklentisi: kullanıcı etkileşimi/paylaşımı nedeniyle çoğu bölgede 12+ / Teen düzeyi ("Kullanıcılar etkileşir", "Kullanıcı tarafından oluşturulan içerik"); gerçek sonuç IARC'ın hesabıdır, hedef kitleyi 18+ olarak ayrıca işaretleyin ([data_safety.md](data_safety.md) bölüm 4).

| Soru | Cevap | Gerekçe |
|---|---|---|
| Şiddet (gerçekçi/çizgi, kan, silahlı) | Hayır | Uygulama içeriği üretmez; yalnız kullanıcı gönderisi/sohbeti |
| Cinsel içerik / çıplaklık | Hayır (uygulama içeriği olarak) | Kullanıcı içeriği kuralları cinsel içeriği yasaklar ([Topluluk Kuralları](../legal/community_rules_tr.md)); raporlama + moderasyon var |
| Küfür / kaba dil | Hayır (uygulama içeriği olarak) | Herkese açık metinlerde uygunsuz ifade filtresi (sohbet hariç) |
| Uyuşturucu, alkol, tütün referansı | Hayır | |
| Kumar / simüle kumar | Hayır | |
| Korku içeriği | Hayır | |
| **Kullanıcılar etkileşir / içerik paylaşır (sohbet, gönderi)** | **Evet** | Birebir/grup sohbet, gönderi, kulüp ve etkinlik sohbeti |
| Kullanıcı tarafından oluşturulan içerik moderasyonu | **Evet** | Raporla, engelle, otomatik gizleme, yönetici paneli, destek |
| Konum paylaşılır | **Hayır** | Konum izni ve toplama yok |
| Kişisel bilgi paylaşılır (herkese açık profil) | **Evet** | Ad, bölüm/fakülte, profil fotoğrafı diğer kullanıcılara görünür (gizlilik ayarlarıyla kısıtlanabilir: [PROFILE_PRIVACY.md](../PROFILE_PRIVACY.md)) |
| Dijital satın alma / uygulama içi ürün | Hayır | |
| Gerçek para ile kumar benzeri mekanik | Hayır | |
| Reklam | Hayır | |

| Hükümet/kamu kuruluşu uygulaması mı | Hayır, resmî değil | Açıklamada açıkça "resmî olmayan, bağımsız" yazıyor |

## Hedef kitle ve içerik (Play "Hedef kitle ve içerik" bölümü)

- Hedef yaş grubu: **18 ve üzeri**.
- Çocukları cezbedebilecek mi: **Hayır** (kampüs/üniversite teması, çizgi film karakteri yok).
- Haber uygulaması mı: Hayır (haberler üniversite sitesinden derleme; uygulama haber kuruluşu değildir). Play "Haber" kategorisi beyanı gerektirmemesi için kategori **Sosyal** seçilir.
- Sağlık, finans, hükümet: değil.
