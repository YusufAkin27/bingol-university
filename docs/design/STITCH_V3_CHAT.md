# STITCH V3 - Sohbet (CHAT) tasarim ozeti

Tam sartname ve PNG'ler repoda degil: `C:\bu_design\stitch\v3_chat\` (SARTNAME.md, kategori klasorleri). Stitch projesi: "BU Kampus Chat UI" (https://stitch.withgoogle.com/projects/17273151393449573964).

Kategoriler (hepsi teslim edildi, Flutter CHAT ajanina bildirildi):
1. `1_konusma_giris` - kullanici onayli "Kampus doodle" sohbet duvar kagidi (acik %7 / koyu %6, 130 dp doseme), konusma ekrani, TEK "+" giris cubugu (kamera dugmesi yok), "+" menusu (Galeri/Kamera karolari + Son fotograflar), mesaj/sohbet menusu, ilet.
2. `2_liste` - sohbet listesi, bos, yukleniyor/cevrimdisi, arsiv.
3. `3_yeni_sohbet` - yeni sohbet, arama, yeni grup, rehberden kisi bul (izin/hazir/bos).
4. `4_galeri` - galeri secici (coklu/tek), album, onizleme + aciklama.
5. `5_bilgi` - sohbet bilgisi (birebir/grup/kulup-etkinlik odasi), uyeler, medya.

Genel kural: tek vurgu `pr`; gonderilen balon dolu `pr`, alinan `sf`+`bd`; tarih/sistem hapi `sf2` dolu; gunluk/gölge/gradyan yok. Stitch'in uydurdugu profil simgesi, "Uctan uca sifreli" vb. etiketler uygulanmaz (bkz. SARTNAME "Uygulanmayacak").
